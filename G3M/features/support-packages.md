# Support Packages

Open **Windows > Support Packager** to save a ZIP for a bug report. G3M does
not upload it.

Choose all logs or logs from the last 24 hours, 7 days, or 30 days. Default
content can include G3M and system details, sanitized settings, logs, installed
mod metadata, selected mod files, game-folder trees, and `.g3mpatch` manifests.

Enable **Custom package settings** to choose entries. Mod configuration, file
trees, and mod files have separate controls.

G3M removes known account, home-folder, and computer names from collected text.
It redacts values with token, password, cookie, API-key, authorization, or
session-like keys. Process records omit command lines. The collector skips
symbolic links.

Review archive contents before sharing. Redaction cannot identify every private
value.
